## Image Recommendations
- **Format**: PNG or WebP (preferred for web performance)
- **Aspect Ratio**: 9:16 for mobile screenshots (portrait)
- **Dimensions**: 1080x1920 or 1125x2436 (iPhone dimensions)
- **File Size**: Optimize for web (use tools like TinyPNG or ImageOptim)
